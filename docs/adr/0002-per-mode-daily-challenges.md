# Daily challenge is structured per game mode, not as one mixed session

The original concept was a single daily challenge of roughly five rounds mixing game modes. We decided instead that each day the player receives one multi-round challenge per enabled game mode (e.g. a Compass challenge, an Arrange challenge, a Border Run challenge), and completing all of them is the full daily ritual; the streak advances only when every enabled mode's required-tier challenge is completed that day, not on partial completion. This keeps each mode's content self-contained and comparable across days, and lets modes be extended (e.g. with difficulty tiers) independently instead of redesigning one shared round sequence. The trade-off is a more complex daily key and generation pipeline (one sub-challenge per mode instead of one flat round list).
